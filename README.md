# Herbis — сайт и личный кабинет

Версия 1.7.0. Самостоятельный сайт на JavaScript и Node.js с SQLite, без внешних npm-зависимостей. В архиве находятся исходники, сервер, тесты и настройки VS Code. База пользователей и секреты в архив не включены.

## Запуск

Откройте всю папку проекта в VS Code. Нужен Node.js 24.14 или новее из ветки 24 LTS; проверено на 24.19.0. Используется встроенный `node:sqlite`, поэтому при обновлении Node проверяйте совместимость.

```powershell
Copy-Item .env.example .env
npm start
```

Откройте [http://127.0.0.1:4174](http://127.0.0.1:4174). `npm install` не требуется. Открытие HTML двойным щелчком или через Live Server не запускает API.

По умолчанию отправка писем отключена. Для локальной проверки поставьте `MAIL_DRIVER=file` в `.env` и перезапустите сервер. Тестовое письмо с кодом появится в `data/mail-outbox/`. Для реальной доставки настройте Resend: [инструкция по email](docs/EMAIL-LOGIN.md).

## Возможности

- Главная страница, таблица тарифов на 1/3/6/12 месяцев, любое количество устройств от 1 до 10: 40 сочетаний и пробный доступ на 3 дня за 1 ₽.
- Перед входом открывается настройка выбранной подписки. Срок, устройства и точная сумма меняются в одном окне. Выбор сохраняется на время прохождения входа; после перезагрузки страницы его нужно выбрать снова.
- Отдельный экран входа: email → одноразовый код → создание и подтверждение пароля для нового аккаунта → кабинет. Имя задаётся позже в профиле. При повторном входе по коду пароль заново не создаётся.
- Пароли хешируются scrypt; серверные сессии используют HttpOnly cookie, CSRF и проверку Origin. Доступ к кабинету нового аккаунта закрыт до создания пароля.
- Настройки профиля и безопасности, смена пароля, завершение остальных сессий. Поддержка сохраняет обращения и ответы в БД.
- Меню кабинета содержит настройки аккаунта, безопасность, промокод, подписку, кошелёк, поддержку и приглашения. На телефоне остаются три нижних пункта: главная, подписка, профиль.
- Персональные реферальные ссылки и учёт завершивших регистрацию приглашённых. Правила в интерфейсе: 3 дня за первое подключение друга, 20% срока за продление. Начисления пока отключены до интеграции оплаты.
- Чёрно-фиолетовая и светлая темы. Переключение сохраняет незавершённые формы; в localStorage хранится только выбор темы. На экране входа есть стрелка на главную.
- Адаптивная вёрстка, плавная прокрутка и появление разделов, анимация цен, поддержка системного reduced motion.
- Новый кабинет: округлые строки настроек, боковое меню из четырёх пунктов на ПК, отдельные страницы данных профиля и обращений, раскрывающиеся ответы поддержки. Тарифы доступны внутри кабинета после входа.
- Миграции SQLite, ограничения запросов, резервное копирование, тесты и GitHub Actions.

## Состояние интеграций

Email-коды реализованы с адаптерами Resend и локальным файловым отправителем. Ключ и домен отправителя настраивает владелец. Telegram, Google и Яндекс показаны как недоступные способы входа до подключения OAuth.

Приём оплаты, активация промокодов, начисление бонусных дней и VPN-панель ещё не подключены. Кнопки не имитируют успешные платежи и не выдают фиктивные VPN-ключи. Нативное приложение и Telegram Mini App — следующие этапы; текущий проект содержит сайт.

## Где менять код

```text
public/index.html                 оболочка страницы
public/assets/views.js            главная, вход и выбор тарифов
public/assets/cabinet.js          страницы и навигация кабинета
public/assets/cabinet.css         оформление кабинета и адаптивность
public/assets/app.js              маршруты, состояние и действия
public/assets/styles.css          базовая вёрстка
public/assets/theme.css           обе темы, адаптивность и анимации
public/assets/theme-preference.js выбор темы до отрисовки
public/assets/motion.js           прокрутка и появление разделов
public/assets/api.js              HTTP-клиент
public/assets/ui.js               форматирование и экранирование
server/app.mjs                    API и раздача статических файлов
server/email-auth.mjs             одноразовые коды и привязка аккаунтов
server/mailer.mjs                 адаптер доставки писем
server/security.mjs              пароли, сессии, ограничения
server/database.mjs               схема SQLite и миграции
server/config.mjs                 переменные окружения
server/plans.mjs                  цены в копейках
server/providers.mjs              интеграция VPN и оплаты
scripts/                         администрирование и резервные копии
tests/                           проверки сервера и интерфейса
```

Внутренние префиксы `orbit` в базе, cookie и ID тарифов сохранены для совместимости с прежними аккаунтами. Публичное название — Herbis. Путь базы можно изменить через `DB_PATH`.

## GitHub и домен

[Как загрузить проект на GitHub](docs/GITHUB.md) · [Инструкция для разработчиков](CONTRIBUTING.md)

В GitHub загружайте исходники. `.env`, `data/`, `backups/` исключены через `.gitignore`. GitHub Pages не запускает сервер Node.js: для кабинета нужен хостинг с Node.js и постоянным диском. Размещайте весь проект, а не только `public/`.

Архитектура рассчитана на один серверный процесс с постоянным диском. Для нескольких экземпляров потребуется отдельная БД и пересмотр сессий, ограничений запросов и фоновых задач.

```text
npm test
```
