# Herbis — открыть и запустить в VS Code

1. Распакуйте ZIP целиком.
2. В VS Code выберите **Файл → Открыть папку** и откройте `herbis-website`, где находятся `package.json`, `public/` и `server/`.
3. Установите Node.js 24 LTS, если он ещё не установлен, и перезапустите VS Code.
4. Откройте **Терминал → Создать терминал**:

```powershell
Copy-Item .env.example .env
```

5. Для проверки входа на своём компьютере откройте `.env` и замените `MAIL_DRIVER=none` на `MAIL_DRIVER=file`.
6. Запустите:

```text
npm start
```

7. Откройте [http://127.0.0.1:4174](http://127.0.0.1:4174). Нажмите «Начать», введите тестовый email. Откройте последнее JSON-письмо в `data/mail-outbox/` и возьмите код из поля `text`. Введите код на сайте, создайте пароль и повторите его. Имя добавляется в профиле.

В режиме `file` письма не отправляются в интернет. Это локальная проверка. Для отправки настоящих писем с сайта на домене используйте [настройку Resend](docs/EMAIL-LOGIN.md).

Зависимости скачивать не нужно. Live Server и двойной щелчок по `index.html` не запускают сервер. Пользователи, пароли и ключи владельца не включены в ZIP: при первом запуске создаётся ваша база.

Если порт занят, поменяйте обе строки `.env`, например:

```dotenv
PORT=4176
APP_ORIGIN=http://127.0.0.1:4176
```

Открывайте адрес из `APP_ORIGIN`. Для остановки нажмите Ctrl+C в терминале. Проверка кода — `npm test`. Отладчик VS Code — F5, «Herbis: сервер».
